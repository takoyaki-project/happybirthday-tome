# happybirthday-tome

自分の誕生日を、自分で盛り上げるブラウザアプリ。**段階1まで実装**。

## 段階1

- 名前（省略可能）とろうそく1〜99本を入力。入力した本数をSVGで描画。
- スタートのタップでWeb Audioを準備し、短い確認音を再生。マイクの許可をリクエスト。
- 約0.8秒の環境音測定後、声量に合わせて「ふーっ！」とメーターが変化。
- 小さめの声が約240ms続くと全体の約1/5、大きな声が約180ms続くと全部消灯。
- 小さめの声の連続判定には950msの間隔を設ける。声・息を識別せず、音量だけを判定する。
- マイク拒否、未対応、準備失敗、切断時はタップで続行。許可待ちでも「マイクを使わずに始める」を選べる。15秒の待機上限あり。
- 画面ロックや別タブへの移動時は入力処理とマイクを停止。残り本数を保ち、「タップして再開」で準備し直す。
- 完了時もマイクを停止。「もう一度、火をつける」で入力からやり直せる。
- 音が聞こえない場合の消音設定・音量の確認案内を常時表示。消音スイッチの状態はブラウザから判定できないため、聞こえたかを自動判定しない。

**段階2（モブ・祝辞・モード）と段階3（伴奏・歌詞）は未実装。依頼どおりここで止める。**

## プライバシーと素材

依存ライブラリなし。HTML / CSS / SVG / JavaScriptとブラウザ標準APIのみ。イラスト画像、音声ファイル、外部フォント、外部AI/API、解析サービスは使わない。

名前・本数はページ内のメモリだけに置く。Cookie、ブラウザストレージ、URLなどへ保存しない。音声は音量測定だけに使い、録音・送信しない。入力はtextContentで表示する。CSPの `connect-src 'none'` で通信も制限。WebMCPなどAI向けの操作連携も追加しない。

サイトのHTML・CSS・JSを取得するためのGitHub Pagesへの通常のアクセスは発生する。入力情報やマイク音声をその通信に含めない。

## 開発

Node.js 24。依存パッケージのインストールやビルドは不要。

```sh
npm run dev
npm run check
npm test
```

WindowsでPowerShellのスクリプト制約がある場合は `npm.cmd` を使用する。ローカルURLは `http://127.0.0.1:4173`。
iPhoneではHTTPSの公開URLで確認する（PCのlocalhostはiPhoneから開けない）。

- `dist/index.html` : 画面とケーキの土台
- `dist/style.css` : レイアウト・炎・吹き出し
- `dist/app.js` : マイク・音声・画面状態とイベント
- `dist/core.js` : 本数検証・配置・声量判定
- `test/` : ブラウザAPIを模した状態遷移テスト、音量判定と配置のテスト
- `.github/workflows/pages.yml` : 検証後に `dist/` のみをPagesへ公開

## 公開

GitHub PagesのSourceを **GitHub Actions** に設定する。mainへのpushで構文・テストを確認し、サイトを公開する。公開予定URL：

https://takoyaki-project.github.io/happybirthday-tome/

非公開リポジトリからのPages公開には対応するGitHubプランが必要。現在のプランが対応しない場合は、リポジトリの公開範囲変更またはプラン変更が必要。

## 確認状況

自動テストで1〜99本の配置、声量判定、マイク拒否・未対応・切断、許可の遅延、画面非表示と再開、タップでの完了を検証。テストのブラウザ・音声APIは模擬実装であり、実際のマイク感度や描画、OSの消音動作を保証するものではない。

この実装環境には接続済みブラウザとiPhoneがないため、Safari実機の確認は未実施。以下の手順で確認する。

## iPhone確認手順（段階1）

iPhoneのSafariで公開URLを直接開く。端末名、iOSバージョン、確認結果を記録する。

| 確認 | 操作 | 期待する動作 |
| --- | --- | --- |
| 初回・音声準備 | 名前と5本を入力し、スタートしてマイクを許可。環境音測定中は静かに待つ | 入力名と5本が表示。タップ後にだけ短い確認音が鳴る。準備OKになったら声量に吹き出しとメーターが反応 |
| 小声・大声 | 小さめの声を0.5秒ほど出し、その後大きな声を出す | 小さめの声で一部、大きな声で全部消える。瞬間的な物音だけでは消えにくい |
| マイク拒否 | サイトのマイク権限を未確認に戻して開き直し、スタート後の要求を拒否。またはサイト設定でマイクを拒否 | 拒否の案内とタップ操作が表示。ケーキ／「タップで消す」で全部消せる |
| マナーモード | 消音をオンにして開始。音が聞こえなければ画面の案内に従い、消音を解除し音量を上げ「確認音をもう一度鳴らす」 | 案内が表示され、消音解除後に音を再確認できる。音がなくてもタップ操作で完了できる |
| 画面を暗くした後 | 一部消した状態でサイドボタンで画面をロックし、10秒後に解除してSafariへ戻る | 一時停止と再開ボタンが表示。残り本数が維持され、タップ後に音・マイクを再準備。再び声が反応 |
| 明るさだけ変更 | 画面の明るさを下げ、Safariへ戻る | 勝手に火が消えない。中断扱いになった場合は再開ボタンで続けられる |
| 99本 | 「もう一度」で99を入力し開始。小さめの声と大きな声、別の回でタップ操作を試す | 99本がケーキ内に並ぶ。小さめの声／1タップで20本消えて残り79本。大きな声で全部、タップのみなら5回で全部消える |
| 境界値 | 1本、0、100、空欄、小数を試す | 1本は遊べる。0・100・空欄・小数では開始されない |
| 再試行 | 完了後「もう一度」、名前・本数を変えて再開 | 新しい入力が反映。消灯状態や以前のマイク処理が混ざらない |
| 保存なし | 名前を入力した後、ページを通常の再読み込み | 名前は空欄、本数は5本に戻る |

マイクの感度は端末・距離・周囲の音で変わる。最初は静かな場所で、端末から20〜30cmほど離れて試す。息を強く吹き付ける必要はなく、声でも遊べる。反応しない場合はタップで続行できる。
