# happybirthday-tome

ブラウザだけで開ける、ろうそくを吹き消す誕生日アプリです。外部AI・API・音声ファイル・追加ライブラリは使いません。

公開URL: https://takoyaki-project.github.io/happybirthday-tome/

## 画面

1ページ内で4つの場面を切り替えます。名前・本数・音声は保存も送信もしません。

- **入力**: 淡い桃色の背景で、名前と1〜99本の必須ろうそく本数を入力します。
- **歌と吹き消し**: 幕とスポットライトのある舞台で、ブラウザ内の音符データによるオルゴール風メロディと、名前入りの歌詞を表示します。歌の間はマイク判定を止め、終了後に「ふーっ」、残り本数、声量ゲージを同時に表示します。
- **暗転**: すべての火が消えると、ケーキを同じ位置に保ったまま煙を約1秒表示します。
- **お祝い**: 金の額縁の中に動的な祝辞を表示し、増えていくモブ、吹き出し、合成した歓声、紙吹雪を表示します。祝辞と掛け声はローカルの `messages.json` から選びます。

ろうそくのない立体ケーキ本体はローカルの透過PNG素材、ろうそくはSVGで別々に描画します。入力本数に応じて、1〜99本のろうそくをケーキ上へ動的に配置します。ケーキは歌・暗転・お祝いで同じ高さに置きます。モブは5種類のローカル透過キャラクター素材を使います。先頭3人が順番に登場し、奥から手前へ4列の波で40人が揃います。最初のモブから約3.6秒、お祝い開始から約4.1秒で登場が落ち着きます。吹き出しは画面内に収まる3体に表示します。

## 操作と音

「お祝いをはじめる」を押すと音を準備し、マイクを許可できる環境では環境音を測定します。スマホだけのモードでは、小さな息でも1回で約3分の1、大きな息なら全部のろうそくを消せます。小さな息や代わりのタップでも最大3回で全部消えます。マイク拒否・未対応・途中切断の場合でも、歌の後はケーキをタップして遊べます。

感度の値は `dist/core.js` の `BLOW_SENSITIVITY` に集約しています。画面ロック・ページ離脱・完了時には、マイクと音声処理を停止します。音が出ないときは画面の案内に従い、マナーモード・消音設定・音量を確認してください。

曲の音符と歌詞の表示タイミングは [dist/song.js](dist/song.js) にまとめています。将来、歌声の音声ファイルへ差し替える場合も、このタイミングデータを調整して利用できます。アプリは歌声や祝辞の読み上げを行いません。

## 開発・検証

Node.js 24。インストールやビルドは不要です。

```sh
npm run dev
npm run check
npm test
node scripts/verify-layout.mjs
```

WindowsのPowerShellでは必要に応じて `npm.cmd` を使います。ローカルURLは `http://127.0.0.1:4173` です。

`node scripts/verify-layout.mjs` は390×844のChromium描画で、入力・歌・マイク代替・暗転・祝福・99本の画面と外部通信なしを確認します。実機のiPhone/Safari、実際のマイク感度、マナーモードはこの自動確認の対象外です。

## iPhoneでの確認項目

Safariで公開URLを開き、再読み込みして最新版を表示します。縦画面、通常の文字サイズ、キーボードを閉じた状態で確認してください。

1. 名前と1本、5本、10本、99本を入力でき、無効な本数では開始できない。
2. マイクを許可すると、歌の間は歌詞だけが表示され、終了後に「ふーっ」・残り本数・ゲージが同時に出る。
3. 小さな息でも最大3回、大きな息なら1回で全てのろうそくが消える。マイクを拒否したときは歌後に最大3回のタップで消せる。
4. 全消灯後に煙が表示され、祝辞・モブ・吹き出し・歓声・やり直し操作が表示される。
5. 画面を暗くしてから戻ったときに再開できる。マナーモード中は音が出ない案内を確認する。
6. 入力後に再読み込みすると、名前は空欄、本数は5本に戻る。

## ぬいぐるみモード（micro:bit）

入力画面の「ぬいぐるみと」を選ぶと、スマホは音だけで micro:bit と連携します。Bluetoothや外部サービスは使いません。クラッカーの絵をタップすると、Web Audioで短い「パーン」という合図を合成します。micro:bit が歌う約12秒間は同じ英語の歌詞だけを表示し、歌い終わってから約1秒は「もうすぐ ふーっ！」、その後に「ぬいぐるみのケーキに ふーっ！」と案内し、「ケーキの上の micro:bit に息を吹きかけてね」と添えます。ぬいぐるみモードではスマホのマイクを使いません。micro:bit のハート表示をスマホが読み取るわけではなく、実機でハートと音が約18秒で出た結果に1秒の余裕を加え、タップから約19秒後にアプリが自動でお祝い（額縁・歓声・モブ）へ進みます。歌が始まらなければ「もう一度鳴らす」で合図とタイマーを最初からやり直せます。実機でのタイミング調整値は `dist/app.js` の `PLUSH_MICROBIT_READY_DELAY_MS` と `PLUSH_CELEBRATION_DELAY_MS` です。

## ぬいぐるみモードをiPhoneで確認する

1. iPhoneのSafariでHTTPSの公開URLを開き、「ぬいぐるみと」を選んで開始する。
2. マイク許可を求められず、2行の「スマホをぬいぐるみの／そばに置いてね」とクラッカーの絵・「タップ」が表示されることを確認する。
3. iPhone本体の音量を上げ、音の出力先を本体スピーカーにする。micro:bitのロゴ右側にあるマイク穴へスマホのスピーカーを数十cmの位置で向け、クラッカーの絵をタップする。LEDとBirthdayメロディ、歌詞4行のタイミングを確認する。歌が始まらない場合は距離を縮めて「もう一度鳴らす」を使う。音量・距離によるレベル180への到達は実機で確認する。
4. 歌が終わって約1秒後に「ぬいぐるみのケーキに ふーっ！」が出て、スマホ側に声量ゲージが出ないことを確認する。micro:bit が息でハートになり、クラッカーのタップから約19秒後にアプリの額縁・歓声・モブが始まるか確認する。
5. micro:bit が歌わなければ「もう一度鳴らす」でやり直す。消音・マナーモードや、画面を暗くして戻った場合も確認する。画面を離れた後は準備画面に戻り、新しいタップから始める。

## 表示と登場の調整（2026-10-06）

トップは「きょうは、あなたが主役。」と短い操作案内に集約。カーテンの位置と高さを保ち、名前・本数の入力欄の高さ、枠線、余白、フォーカス表示を統一しています。モードの選択色は淡いプラム、開始ボタンは深い紫とし、操作の優先順位を示します。歌の一時停止時は「タップして再開」を画面の左右中央に表示します。ぬいぐるみの案内は2行で固定し、クラッカーの絵と「タップ」で開始します。歌詞本文は `SONG` と `PLUSH_SONG` で共有し、表示時刻だけを分けています。

モブの調整値は `dist/app.js` 冒頭にまとめています。

| 定数 | 初期値 | 意味 |
|---|---:|---|
| `MOB_START_DELAY_MS` | 500 | 額縁からモブ開始までの待ち時間（ms） |
| `MOB_SOLO_INTERVAL_MS` | 280 | 最初の3人の登場間隔（ms） |
| `MOB_WAVE_INTERVAL_MS` | 560 | 列から次の列までの間隔（ms） |
| `MOB_WAVE_STAGGER_MS` | 24 | 同じ列の左から右へのずれ（ms） |
| `MOB_ARRIVAL_MS` | 600 | 1体が定位置に落ち着くまで（ms） |

`node scripts/verify-layout.mjs` は従来の確認に加え、320×700、375×667、390×844、430×932で、文字と吹き出しの収まり・クラッカー画像・英語歌詞・モブの実時間の登場を検証します。動きを減らす設定と通常のアニメーションの両方を確認します。スクリーンショットと計測値は `verification/review-2026-10-06/` に出力します。
