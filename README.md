# happybirthday-tome

ブラウザだけで開ける、ろうそくを吹き消す誕生日アプリです。外部AI・API・音声ファイル・追加ライブラリは使いません。

公開URL: https://takoyaki-project.github.io/happybirthday-tome/

## 画面

1ページ内で4つの場面を切り替えます。名前・本数・音声は保存も送信もしません。

- **入力**: 淡い桃色の背景で、名前と1〜99本の必須ろうそく本数を入力します。
- **歌と吹き消し**: 幕とスポットライトのある舞台で、ブラウザ内の音符データによるオルゴール風メロディと、名前入りの歌詞を表示します。歌の間はマイク判定を止め、終了後に「ふーっ」、残り本数、声量ゲージを同時に表示します。
- **暗転**: すべての火が消えると、ケーキを同じ位置に保ったまま煙を約1秒表示します。
- **お祝い**: 動的な祝辞、増えていくモブ、吹き出し、合成した歓声、紙吹雪を表示します。祝辞と掛け声はローカルの `messages.json` から選びます。

ケーキとろうそくはSVGで別々に描画します。入力本数に応じて、1〜99本のろうそくをケーキ上へ動的に配置します。モブも一枚絵ではなく、最大40人まで増えます。

## 操作と音

「お祝いをはじめる」を押すと音を準備し、マイクを許可できる環境では環境音を測定します。小さな息で一部、大きな息で全部のろうそくを消せます。マイク拒否・未対応・途中切断の場合でも、歌の後はケーキをタップして遊べます。

感度の値は `dist/core.js` の `BLOW_SENSITIVITY` に集約しています。画面ロック・ページ離脱・完了時には、マイクと音声処理を停止します。音が出ないときは画面の案内に従い、マナーモード・消音設定・音量を確認してください。

曲の音符と歌詞の表示タイミングは [dist/song.js](dist/song.js) にまとめています。将来、歌声の音声ファイルへ差し替える場合も、このタイミングデータを調整して利用できます。アプリは歌声や祝辞の読み上げを行いません。

## 開発・検証

Node.js 24。インストールやビルドは不要です。

```sh
npm run dev
npm run check
npm test
node scripts/verify-layout.mjs
```

WindowsのPowerShellでは必要に応じて `npm.cmd` を使います。ローカルURLは `http://127.0.0.1:4173` です。

`node scripts/verify-layout.mjs` は390×844のChromium描画で、入力・歌・マイク代替・暗転・祝福・99本の画面と外部通信なしを確認します。実機のiPhone/Safari、実際のマイク感度、マナーモードはこの自動確認の対象外です。

## iPhoneでの確認項目

Safariで公開URLを開き、再読み込みして最新版を表示します。縦画面、通常の文字サイズ、キーボードを閉じた状態で確認してください。

1. 名前と1本、5本、10本、99本を入力でき、無効な本数では開始できない。
2. マイクを許可すると、歌の間は歌詞だけが表示され、終了後に「ふーっ」・残り本数・ゲージが同時に出る。
3. 小さな息で一部、大きな息で全てのろうそくが消える。マイクを拒否したときは歌後にタップで消せる。
4. 全消灯後に煙が表示され、祝辞・モブ・吹き出し・歓声・やり直し操作が表示される。
5. 画面を暗くしてから戻ったときに再開できる。マナーモード中は音が出ない案内を確認する。
6. 入力後に再読み込みすると、名前は空欄、本数は5本に戻る。
