# happybirthday-tome

ブラウザ内で動く誕生日アプリ。段階1まで。段階2・3には進んでいません。

公開URL: https://takoyaki-project.github.io/happybirthday-tome/

## 画面

上からタイトル「HAPPY BIRTHDAY TO ME.」「ひとりでも、主役。」、1枚のカード、ケーキ。

- 入力前のカード: 「本日の主役、入場です。」「自分に、おめでとう。」、名前、本数（1〜99）、パーティスタート。
- スタート直後: カード内が「今日の主役へ」「願いごと、決まった？」「願いごとをひとつ。あとは、思いっきりふーっ。」に切り替わり、入力欄とスタートボタンは消える。
- カードの高さは同じ。ケーキの位置は変わらない。
- 「ふーっ！」と「あと◯本」は共通の `#blow-cue` に入り、`updateBlowCue()` の1か所で表示を管理。入力前・一時停止・完了では一緒に非表示、スタート直後・再開時は一緒に表示。歌の実装時は、この関数の表示条件を歌の完了に合わせる。
- 余分な見出し、説明、メーター、ヘッダー、フッターは削除。
- マイク拒否時の操作案内、再開ボタンは必要なときだけ表示。カード右下のスピーカーで確認音とマナーモードの案内、回転矢印でもう一度。通常時の説明文は表示しない。

## 音・プライバシー

スタートのタップで音を準備し、マイクを要求。環境音測定後、小声で一部、大声で全部のろうそくを消す。マイクを使えなくてもケーキのタップで遊べる。画面ロックやページを離れたとき、完了時にマイクを停止する。

今回の画面変更では `dist/core.js` と、音量のしきい値・平滑化・環境音測定時間・連続判定間隔を変更していない。

外部AI/API・追加ライブラリ・画像素材・音声ファイルは使用しない。名前・本数・音声を保存、録音、送信しない。入力値は現在のページのメモリだけにある。サイトの静的ファイル取得以外の通信は行わず、CSPは `connect-src 'none'`。画像はCSS・SVGのみ。

## 開発・検証

Node.js 24。インストールやビルドは不要。

```sh
npm run dev
npm run check
npm test
```

WindowsのPowerShellでは必要に応じ `npm.cmd` を使用。ローカルURLは http://127.0.0.1:4173 。公開はmainへのpush後、GitHub Actionsで検証して `dist/` のみをPagesに配信する。

390×844の実描画検証（Windows、Edgeインストール済み環境）:

```sh
node scripts/verify-layout.mjs
```

専用の一時プロファイル `.qa/` とNode.js標準機能のみを使用。ライブラリ追加なし。検証用に無音のマイクストリームを模擬し、実際のマイクは使用しない。`EDGE_PATH` 環境変数で実行ファイルを指定できる。

## iPhoneでの確認項目

Safariで公開URLを開き、再読み込みして最新版を表示する。縦画面、通常の文字サイズ、キーボードを閉じた状態で確認。

1. **入力前**: タイトル → 入力カード → ケーキの順。画面がスクロールせず、カードの指定文言・入力欄・「パーティスタート」とケーキ全体が見える。「ふーっ」と残り本数はまだ出ない。
2. **スタート後**: 名前と本数を入力してタップ。入力欄とボタンが消え、指定の3文に切り替わる。ケーキが上下に動かず、全体が1画面に収まる。吹き出しと残り本数が同時に現れる。
3. **マイク許可**: 約2秒静かに待ち、小さめの声で一部、大きな声で全部消える。吹き出しが声量に反応。完了時は吹き出しと残り本数が同時に消える。
4. **マイク拒否**: 権限を拒否して開始。カード内の案内が見え、ケーキをタップして最後まで消せる。
5. **マナーモード**: 消音をオンにして開始。カード右下のスピーカーを押すと確認音と案内が出る。消音を解除し音量を上げ、もう一度押して音を確認する。消音状態をアプリが自動判定する仕様ではない。
6. **画面を暗くした後**: 一部消した状態で画面ロックし、10秒後に戻る。「タップして再開」を押し、残り本数を保って続けられる。吹き出しと本数は停止中に一緒に消え、再開時に一緒に戻る。
7. **99本**: 回転矢印で入力に戻り99本を入力。ケーキ全体が収まり、開始前後で位置が変わらない。タップ1回で残り79本、5回で全部消える。
8. **保存なし**: 名前を入力した後に再読み込みすると、名前は空欄、本数は5本に戻る。

ここで止める。モブ・祝辞・モード・歌は追加していない。
