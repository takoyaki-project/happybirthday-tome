# happybirthday-tome

ブラウザ内で動く誕生日アプリ。段階3まで。段階4（伴奏・歌詞同期）には進んでいません。

公開URL: https://takoyaki-project.github.io/happybirthday-tome/

## 画面

4つの場面を1ページ内の状態切り替えで表示します。URL遷移、外部API、追加ライブラリは使いません。

- **入場**: タイトル、名前、本数（1〜99）、パーティスタート。ケーキは表示しない。
- **歌**: 暗い背景にケーキ、仮の歌詞表示、ふーっの吹き出し、残り本数、声量ゲージを表示する。段階4で歌を実装するまでは、開始直後から吹ける。
- **暗転**: すべて消えると、ケーキは同じ位置のまま暗くなり、細い煙だけを1秒表示する。
- **祝福**: 明るい背景へ戻り、`messages.json` の祝辞を表示してブラウザの読み上げで読む。モブは10人から始まり、40人まで増える。ケーキは歌・暗転と同じ位置・大きさで、消えた状態を保つ。
- 「ふーっ！」と「あと◯本」は共通の `#blow-cue` に入り、歌では一緒に表示、暗転・祝福では一緒に非表示になる。
- 右上の回転矢印で入場へ戻る。マイクが使えないときもケーキのタップで消せる。

## 音・プライバシー

スタートのタップで音を準備し、マイクを要求。環境音測定後、小声で一部、大声で全部のろうそくを消す。マイクを使えなくてもケーキのタップで遊べる。画面ロックやページを離れたとき、完了時にマイクを停止する。

開始後、確認音が終わってから約800msの環境音を測り、中央値を基準値にする。その基準値との差でゲージと消灯を判定するため、部屋の常時音に反応しにくい。通常の声は約1秒でゲージが満ち、小さめの吹きで一部、大きめの吹きで全部を消す。感度値は `dist/core.js` の `BLOW_SENSITIVITY` に集約している。待機中はゲージの数値も表示し、カード右下の「数」で表示・非表示を切り替えられる。数値の設定は保存しない。

外部AI/API・追加ライブラリ・画像素材・音声ファイルは使用しない。祝辞とモブの掛け声はローカルの `messages.json` にあり、直近5回の祝辞を避けて選ぶ。名前・本数・音声を保存、録音、送信しない。入力値は現在のページのメモリだけにある。サイトの静的ファイル取得以外の通信は行わず、CSPは `connect-src 'none'`。画像はCSS・SVGのみ。

## 開発・検証

Node.js 24。インストールやビルドは不要。

```sh
npm run dev
npm run check
npm test
```

WindowsのPowerShellでは必要に応じ `npm.cmd` を使用。ローカルURLは http://127.0.0.1:4173 。公開はmainへのpush後、GitHub Actionsで検証して `dist/` のみをPagesに配信する。

390×844の実描画検証（Windows、Edgeインストール済み環境）:

```sh
node scripts/verify-layout.mjs
```

専用の一時プロファイル `.qa/` とNode.js標準機能のみを使用。ライブラリ追加なし。検証用に無音のマイクストリームを模擬し、実際のマイクは使用しない。`EDGE_PATH` 環境変数で実行ファイルを指定できる。

## iPhoneでの確認項目

Safariで公開URLを開き、再読み込みして最新版を表示する。縦画面、通常の文字サイズ、キーボードを閉じた状態で確認。

1. **入場**: ケーキが表示されず、名前・本数・ボタンがキーボードに隠れずに操作できる。
2. **歌**: 開始後に暗くなり、歌詞の仮表示、ケーキ、吹き出し、残り本数、ゲージが見える。小さな吹きで一部、大きな吹きで全部消える。
3. **暗転**: 全消灯後に約1秒暗くなり、煙が見えたあと祝福へ変わる。暗転中に画面が固まったように見えない。
4. **祝福**: 明るく戻り、名前入りの見出し、`messages.json` の祝辞、10人以上のモブと消えたケーキが表示される。読み上げが聞こえないときは、画面のマナーモード案内を確認する。歌・暗転・祝福でケーキが動かない。
5. **マイク拒否・マナーモード・画面ロック後・99本**: マイク拒否時はタップで消せる。消音時はスピーカーで案内が出る。画面を暗くしたあと再開でき、99本でも崩れない。
6. **保存なし**: 名前を入力した後に再読み込みすると、名前は空欄、本数は5本に戻る。

ここで止める。段階4の伴奏、歌詞の同期表示、歌の間のマイク停止は追加していない。
